# use-smithy

The router. The agent loads it at the start of coding work: it lists the installed smithy
skills, sends each piece of work to the one that fits and holds the rules they share. Install
it with the others; without it the agent knows them only by their one-line descriptions.

| You want… | It routes to |
|---|---|
| to build, change or fix code | **smelt** |
| several tasks at once | **warden**, after your yes |
| a fact or comparison | **scout** |
| a decision recorded, docs | **ledger** |
| open PRs kept green | **tend** |
| the work done without talk | **hush** |

Setup: ask your agent to **"run use-smithy setup"**. It shows every setting, asks the unset
ones with a recommendation, offers a pointer block for your `AGENTS.md` / `CLAUDE.md` and
offers to put `smithy` on your `PATH`. Nothing is written without a yes.
